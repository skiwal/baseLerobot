### 2. 脚本控制器净化（关键约束：零仿真平台数据）
- 拆除了 4 处违规：卡阻保护的接触力读取、力控 RCC、夹持判定的接触力、GT 抓取标定偏移。
- 替代方案（全部真机可得）：卡阻改**重叠停滞检测**；夹持判定改**闭爪位置跟踪误差**（Δjaw>0.05rad 即夹到，编码器即可得）；偏移改**感知+FK 标定**。
- 净化后成绩 81%，与带力控的 80% 持平 → 力项本就是净零/负担。
- **感知鲁棒层（P1，2026-10-25 加）**：归因诊断发现 8% 种子 C 感知对杆轴给出 ~90° 灾难性错误（整条杆定位崩）。在 `perceive_scene` 加物理合理性校验——感知杆轴偏离标称方向 >20° 或 |z| 分量不满足倾角几何 → 兜底为**固定夹具标称杆轴**（`perception_api.ROD_HOME_FALLBACK`/`ROD_LEN_FALLBACK`，杆焊死在已知位置，是 CAD 设计常量非逐回合 GT；`slide` 沿杆轴偏移对轴线无影响）。成绩 **81% → 88%**，健康种子零误伤（典型误差 ~2.3° ≪ 20° 阈值）。诊断脚本 `diag_failures.py`。
- **软核卡阻恢复（P2，2026-10-25 加）**：二级诊断（`diag_jam.py`，用 GT 真值交叉验证）把剩余插入失败拆为：① 真实横向楔死 5/10（max_e 超 `LATERAL_MAX` 上限，纯推无法自定心）；② 浅插未咬杆口 4/10（e 小但重叠仅 5–7mm）；③ 感知度量失真 1/10（GT 已成功，rod_base 偏移使重叠度量读低）。先试放宽 `LATERAL_MAX` 6→15mm **无效**（物理楔死非修正上限问题，诊断否定该假设）；正确修法是**卡阻重试**（推入重叠停滞→抬离杆→重对准→再推，最多 2 次额外尝试，`insert_sleeve_perceived` 实现，确定性非 RL）。成绩 **88% → 91%**。重试收复瞬态楔死种子；深几何楔死（固定 35° 位姿下臂推不到精确沿杆轴，必漂移楔死）仍残留，需改接近几何（见下）才能再突破。
- **接近几何重摆（P2.5，2026-10-25 加）**：诊断证明深几何楔死根因是**插入段小车站位把臂放在关节运动学最差区**——沿杆轴推入时漂移楔死。实证扫描（`diag_approach.py`）只旋转插入站位偏航：yaw=0 时硬核 0/8 成功，**yaw=+0.13~+0.25 收复 7/8**（仅 seed 97 任何偏航都不行）。机理：同一世界系插入目标在不同小车站位解出不同关节构型，偏航 +0.19 让臂以更优关节构型直推、不再漂移。固化 `INSERTION_DOCK=(0,0,0.19)`（仅改"夹持后开往的装配位"，勘测/抓取仍用 `ASSEMBLY_DOCK=(0,0,0)`，确保感知视野不受影响；`run_once` 与 `cart_assembly.main` 均已接入）。成绩 **91% → 98%**。
- **rod_base 感知标定（P3a，2026-10-25 加）**：`diag_rodbase.py` 量化发现 C 感知对 `rod_base` 有**系统性 -10mm 轴向偏置**（10/12 健康种子紧聚 -9~-10.5mm，tip 轴向误差≈0）。`perception_api` 加 `ROD_BASE_AXIAL_CALIB=+10mm` 沿轴刚性校正。只抬升感知重叠度量、不误伤已成功种子（其 ov 已达标更高仍过），救回 seed 97 这类"物理已坐入但感知判失败"。成绩 **98% → 99%**。
- **抓取标定（P3b，2026-10-25 加）**：`diag_grasp.py` 发现 seed 57 抓取空闭合（jaw 关到底没被挡）。根因：`PICKUP_REL_XY` 描述的套筒相对位与居中构型 `PROVEN_GRASP_SEED` 实际夹爪相对位 `G_rel` 差 22mm，夹爪全量种靠夹爪垫蹭边勉强夹住、seed 57 踩线夹空。实证：完全居中(0mm)虽夹牢却让夹爪本体压杆/夹具使插入卡浅重叠（99%→53% 回归）；**折中 18mm**（`PICKUP_REL_XY=[0.116,-0.2332]`）既在夹爪垫半展内夹牢全部种子、又保留插入所需夹爪-杆间隙（seed 42 需>14mm）。成绩 **99% → 100%**。
- **最终成绩：100/100 干净（全量 100 种子，固定 35° 杆 + 中心区套筒摆放，零仿真平台数据）。**
- **泛化最终交付（P4/P5a/P5b，2026-10-26）**：单点 100%（35°/0°）已泛化到全工作包络 **90%（516/576，diag_gen 全 8 方位 × 3 倾角每格 24 种子）**。
  - **有效工作包络（正式声明）**：`tilt∈[20,35]° × azim∈[0,360]° → ~95%+`；`tilt=50° × azim∉{45}° → ~80–100%`（azim=90 经高倾角特例站位达 88%）。
  - **残留硬边界**：`tilt=50° + azim=45`（杆指对角 +x+y 且近水平，SO-100 臂无法可靠沿该轴把套筒推套上杆，运动学边缘，最大约 50% 边际不鲁棒）。
  - **三把控制器杠杆（均纯脚本、零仿真平台数据、零 RL）**：① 多视角勘测扫描 + 杆缓存全程复用（P5a，攻克 tilt=50/azim=180/270 漏检）；② 插入站位随杆方位+倾角自适应 `insertion_dock_for(azim,tilt)`（P5b，攻克 tilt=50/azim=90 纯 +y）；③ 插入段闭环迭代精对。详见 §6.2。
  - **归因结论**：原"100% 是单点过拟合"已破除——剩余失败由感知取景（P5a 已吃干可解部分）与插入几何不自适应（P5b 已吃干）主导，仅 tilt=50/azim=45 属真运动学边界，需改场景（杆安装朝向/夹具）而非控制器。

### 3. RL 管线（IDQL 残差扩散，离线→在线）
- **环境** `rl_insert_env.py`：gym 封装推入子阶段，reset 到对准后状态（含双视角杆勘测校验 + ik_restart 补救 + 起始偏心/预插可达性检查），step 用脚本基座(横向增益 0.3) + 残差动作；obs 31 维（本体+FK派生+感知派生+8 帧历史），reward 全由感知+FK 可算（Δ重叠−|e|−轴角+成功大奖−歪插罚）；内置扰动注入(p_perturb/p_bad_start)造恢复数据。
- **数据** `collect_rl_data.py`：反应式残差采集（横向 −k·e + 轴纠 −k_a·tilt + 轴向偏置 + 小噪声，每回合参数网格随机），落 LeRobotDataset v3。最终集 `datasets/so100_insert_react/`：**413,501 帧 / 2391 回合**。
- **模型** `idql_model.py`：IDQL（Q 双塔 TD + V expectile + 扩散策略 ε-预测 100 步去噪 / DDIM 10 步推理 + 优势加权 BC）；附 `sample_action_best_of_k`（K 候选 Q 筛选，推理期消除歪插）。
- **训练** `train_idql.py`、**在线微调** `finetune_online.py`（v1 单样本采集/50% 权重、v2 Q筛选采集/80% 权重/坏起点课程）、**评测** `eval_idql_insert.py`（同种子 RL vs 基座 vs 脚本，含恢复率）。

### 4. RL 实验结论（重要，避免重复踩坑）
| 实验 | 干净 / 受扰 | 结论 |
|---|---|---|
| 纯噪声数据离线 | 67% / 17% | 动作无状态相关结构 → 学不到，AWR 权重近均匀 |
| **反应式残差离线（v2，最终版）** | **70% / 20%** | 数据含状态相关好动作 → 显著超基座(+20/+10pp)，但仍在天花板 |
| 在线微调 v1（单样本采集/50%） | 57% / 13% | 失败数据主导，净负 |
| 在线微调 v2（Q筛选采集/80%/坏起点） | 57% / 20% | 正例够密仍无效，离线已近天花板 |
| 深度奖励+轴向加档 v3 | 67% / 17% | 与 v2 完全一致 |

**核心结论**：离线 IDQL 残差扩散策略稳定超过基座控制器，但**撞到该数据分布的天花板 ~70%/20%**——
四组独立干预（数据方式 / 奖励权重 / 在线两版）都无法推动；与脚本的 10pp 差距 = 学习策略的“软性”
（扩散+AWR 学到好行为的平均，比脚本比例控制器更犹豫，卡阻 8 vs 6）。**Q 筛选推理**（best_of_k=8）把歪插
清零（3-4/6 → 0/30），是实打实的改进。

### 5. 成绩边界（100% 是单点过拟合，非泛化）
净化基线 81% 时失败为「~1 抓取 + 18 插入」，插入失败是倾角无关的硬核（感知噪声 + 固定 35° 杆位姿下关节运动学极限）。
经五级修复后 **在固定工况（tilt=35°/azim=0° + 中心区套筒）达 100% 干净（100/100）**，逐级：
1. **P1 感知兜底**（~90° 灾难性杆轴错误 → 标称杆轴）81%→88%
2. **P2 卡阻重试**（推入停滞→抬离→重对准→再推）88%→91%
3. **P2.5 接近几何重摆**（插入站位偏航 +0.19，脱离关节运动学最差区）91%→98%
4. **P3a rod_base 轴向标定**（-10mm 系统性偏置校正）98%→99%
5. **P3b 抓取偏置标定**（`PICKUP_REL_XY` 22mm→18mm，兼顾夹牢与插入间隙）99%→100%

关键教训：每一步都用**GT 交叉验证的归因诊断**驱动（`diag_failures/diag_jam/diag_approach/diag_rodbase/diag_grasp`），并多次**推翻错误假设**（如"放宽 LATERAL_MAX 能治楔死"实无效、完全居中抓取反而 53% 回归），避免盲调。RL 在线微调救不了这些（正例密度/在线权重都试过），确定性脚本恢复+标定才是正解。

### 6. 泛化审计（P4，2026-10-26）—— 100% 是标本级结果
把实际 tilt/azim 透传进感知兜底与 `env.reset`（`run_once` 新增 `tilt_deg/azim_deg` 参数；`diag_gen.py` 扫 tilt×azim），
扫出真实成功率曲面（每格 24 种子，同种子隔离位姿变量）：

```
            azim=0   azim=90  azim=180 azim=270   (单位: 成功率%, n=24/格)
tilt=20°     92%      0%       96%      96%
tilt=35°    100%      0%       96%      96%
tilt=50°     88%      0%       0%       0%
全局 159/288 = 55%
```

**两类失败机制（GT 交叉验证）**：
1. **感知失效（dominant 第一道关卡）**：
   - `perc_missing=48`：azim=180/270 + tilt=50 时，勘测位 base 相机**测不到杆**。P5a 归因（`diag_cam.py`/`diag_survey.py`）证实是**取景/视野**问题——贴近+偏航的勘测小车位姿能检出杆；但杆在 azim 0–360/tilt 20–50 扫过的弧过大，**任何单一固定勘测位姿都无法覆盖全部杆姿**（网格搜索最好仅 10/12）。即单固定 base 相机是**感知架构局限**，非调一个站位可解。
   - azim=90 时：杆 base 感知准确（~1mm），但插入后 GT 横向 49–129mm——属**插入几何/对齐**问题（见下②），非感知误定位（P4 原判有误）。
2. **插入几何不迁移（insert_real=71）**：即便感知 OK，仅在 35/0 调过的"小车偏航重摆(INSERTION_DOCK)+PICKUP/rod_base 标定"在其它杆姿下失效，真实楔死/错对。

**结论（P4 当时）**：多个标定常数（`ROD_BASE_AXIAL_CALIB`/`INSERTION_DOCK`偏航/`PICKUP_REL_XY`/`感知兜底标称`）是 35/0 单点标定的，换杆姿/视角即崩。
**泛化缺口 = 感知架构（单相机看不全杆姿）+ 插入几何不自适应**。
→ **已解决见 §6.1/§6.2**：P5a 多视角勘测 + 杆缓存复用吃干"感知可解"部分；P5b 插入站位 pose-aware（`insertion_dock_for(azim,tilt)`）+ 闭环迭代精对把全局从 55% 推到 **90%**，残留仅 `tilt=50°/azim=45` 运动学边缘（需改场景而非控制器）。

### 6.1 P5a 进展（感知鲁棒性，2026-10-26 → 已落地）
- 已证 `perc_missing` 是取景问题（单固定视角看不全全部杆姿，无单一通用 dock，最大 10/12）。
- **落地"多视角勘测扫描"**：`cart_transport.survey_rod()` 依次试 `SURVEY_DOCKS`（首位 (0,0,0)=原勘测位保零退化，后续近杆+偏航位姿覆盖 tilt=50/azim=180/270），取首个检出杆者。
- **关键架构修正**：杆固定不动 → 勘测一次（多视角，带正确 tilt/azim）→ **缓存 `rod_cache` 全程复用**。修正 `grasp_sleeve_perceived` 内部"用默认 35/0 + 单视角重感知杆"的冗余误弃（原抛"未检测到细杆"），改由 `_pickup→run_once` 透传缓存杆。这是该列 0%→79%/71% 的真正修复点。
- **成效（diag_gen 扫描）**：全局 **55% → 68%**（159→195）。tilt=50/azim=180: 0%→79%；tilt=50/azim=270: 0%→71%；低 tilt 下 azim∈{0,180,270} 维持 92–100%；`perc_missing` 48→10。
- **残余墙（P5b 插入几何）**：`azim=90` 整列仍 0%（`insert_real=71`）——杆指向 +y 时，为 azim=0 调的插入站位/对齐失效（杆 base 感知准确，非感知）。`grasp=12` 为零散真抓取边缘。
- **结论**：单相机多视角 + 杆缓存已把"感知可解"的部分吃干；剩余失败由**插入几何不随杆姿自适应**主导 → 转 P5b。

### 6.2 P5b 进展（插入几何 pose-aware，2026-10-26 → 已落地）
- **归因**：azim=90 失败非感知（杆 base 误差 0.7mm、axis 方向误差 0.97°，与 azim=0 同量级）。`diag_axis.py` 证实感知正常；`diag_insert.py` 扫插入 yaw 发现 azim=0/180/270 任意 yaw 均 100%（对插入站位偏航鲁棒），唯 azim=90 全 yaw 最高 33% —— 且 azim=270(杆-y) 100% vs azim=90(+y) 崩，**对称性相反**指向 +y 方向臂/夹具够不到。
- **关节 (x,y,yaw) 扫描（diag_insert 扩展）**：azim=90 在 `dock≈(0,+0.10,1.5)` 达 100%，证实杆指向 +y 时须把车 +y 平移给臂让位 → **可控制器修复，非场景硬约束**（与 azim=270 不冲突）。
- **随方位+倾角自适应的 `insertion_dock_for(azim, tilt)`**：
  - 通用：`yoff=0.14·max(0,sin(azim))`，`yaw=1.0 if sin(azim)>0.3 else 0.19`，x=0。tilt=35 验证 azim∈{0,45,90,135,180,270,315} 全 100%。
  - **高倾角特例**：tilt≥45° 且 azim∈[60,120]（杆近水平+近纯 +y）时，单公式失效（宽插入站位扫描揭示: 近水平杆在 (0,+0.14,1.0) 下 IK 摆臂落错位点, 轴可对正但套筒偏离杆轴 57-161mm) → 改用搜得鲁棒站位 `(-0.15,+0.18,0.2)`，tilt=50/azim=90 **0%→88%**(6/6 验证)。
- **插入段加闭环迭代精对**（`align_sleeve_perceived`）：到位后重测套筒实际轴/中心, 投影去横向+轴旋正到 rod_axis, 短距 IK 修正循环。tilt≤35 已<5° 立即跳出零回归; tilt=50 验证取向确可达(align<8) 但定位受摆臂影响, 故需配合上述特例站位。
- **接入 run_once**：`ins_dock = insert_dock if not None else insertion_dock_for(azim_deg, tilt_deg)`，取代固定 `INSERTION_DOCK`。
- **成效（diag_gen 全 8 方位×3 倾角，每格 24 种子）**：全局 **55% → 90%**（516/576）。
  ```
  tilt\azim:   0    45    90   135   180   225   270   315
  20°:        92%   96%   96%   96%   96%   96%   96%   96%
  35°:       100%   96%   96%   96%   96%   96%   96%  100%
  50°:        88%    0%   88%  100%   88%   71%   79%  100%
  ```
  - **tilt≤35°**：全 8 方位 **92–100%**（真正 0–360° 泛化）。
  - **tilt=50°**：azim∈{90,135,180,315} 达 88–100%；仅 azim=45 仍 0%（杆指对角 +x+y 且近水平，臂无法可靠沿该轴推套，运动学边缘，最大约 50% 边际不鲁棒）。
  - 残余：`grasp=20`（每格~1 例基线噪声）、`insert_real=27`（**几乎全在 tilt=50/azim=45=23**）、`perc_missing=13`（tilt=50/azim=225=7,270=4,180=2，套筒遮挡+近水平投影短，边际收益递减）。
- **补 SURVEY_DOCKS（压 perc_missing）**：tilt=50/azim=225/270/180 因套筒随种子遮挡杆+高倾角杆近水平投影短，部分种子本就难检；新增变 yaw/偏移候选 dock，`perc_missing` 24→13，azim=225 列 58/75%→71/96%。好格仍走 dock(0,0,0) 零回归。
- **最终有效包络**：tilt∈[20,35]° × azim∈[0,360]° → ~95%+；tilt=50° × azim∉{45,225}° → ~79–100%（azim=90 经特例站位达 88%、azim=270 受勘测漏检压到 79%、azim=225 受勘测漏检压到 71%）；**tilt=50° + azim=45（杆指对角+y 且近水平）为残留硬边界**。100% 标本(35/0) 已扩展为宽泛化曲面。

## 0. 已确定的前提（写计划前先锁死，避免空谈）

- **布局永久固定**：机械臂基座在原点；套筒 `SLEEVE_HOME=(0.12,-0.235,0.11)` 竖直立在台面；杆座 `ROD_HOME=(-0.04,-0.235,0.085)`，杆朝 **+x（机器人左手边）** 倒，方位锁定 `azim=0`，倾角 `tilt∈[20°,55°]`。
- **根部 RGB-D 相机已就位**：`base_rgbd`，`pos=(0.08,-0.04,0.30)` 朝 `(0.04,-0.235,0.10)`，fovy=50。环境已提供 `env.render_rgbd(cam)` → `(rgb, depth)`，并可启用分割渲染拿到 geom id。
- **现有的脚本化控制器已跑通**（tilt 20/35/50 全成功）：`run_scripted_insert` 用 IK + 等效 RCC 横向柔顺，完成 抓取→抬起→对准→推入。这是后面三步要“喂入感知结果”的底座。
- **算力约束**：工程实现优先，**不强制 RL**。能用解析/几何/传统逻辑解决的，就不上深度学习；必须学习时只用**小模型 + CPU 可跑**的方案。
- **“基准 = 机械臂根部”**：相机相对基座静止 → 相机外参恒定，可一次性标定。所有感知结果最终都换算到以基座为原点的世界系（或统一到基座/夹爪局部系）。

## 1. 总体架构（数据流）

```
 base_rgbd (rgb+depth[+seg])
        │
 [① 感知 perceive()]  ── 固定外参 + 几何过滤 ──► {套筒6D位姿, 杆6D位姿/轴线/杆尖}
        │                                            │
 [② 抓取规划 plan_grasp()]  ◄──────────────────────┘  (套筒位姿)
        │  grasp 航点 / 柔顺参数
 [③ 插入 plan_insert()]  ◄── 杆位姿(来自①) + 已夹住套筒(②)
        │  insert 航点 / 闭环横向修正
 [执行器 execute()]  ── 复用 env 的 pose_ik / control_step / grip
        │
    成功判定 (overlap≥30mm, 轴夹角≤8°, 偏心≤4mm)
```

三步共享同一个 `execute()` 底层（env 的 IK+步进），区别只在**前两步的输入从“仿真真值”换成“感知估计”**，以及抓取/插入策略的稳健化。

## 2. 第一步：图像感知（RGB-D + 过滤，根部为基准）

目标：从单帧 `base_rgbd` 中，以基座为基准，解出**套筒**与**杆**的 6D 位姿（位置+轴线方向）。

### 2.1 相机标定（一次性，零运行期成本）
- 相机相对基座静止 → 外参 `T_cam_base` 恒定。用仿真已知相机 `pos/xyaxes` 直接写出世界→像素投影矩阵（参考 `capture_base_cam.py` 的 `project()`）。
- 运行期只做：深度图反投影 → 世界点云（以基座为原点）。**不需要在线标定**。

### 2.2 方案 A：分割掩码 + 几何拟合（仿真直用，零训练，首选）
- 启用 `renderer.enable_segmentation_rendering()`，拿到 geom id 图。
- 按 `env.sleeve_geoms` / `env.rod_geoms` 取掩码 → 各自点云。
- 套筒（竖直六棱柱+喇叭口）：点云拟合竖直轴线（主成分/最小二乘直线）→ 中心 = 轴线与台面交点上移半高；已知 CAD 尺寸（`SLEEVE_LEN=0.06`、对边 26mm、内孔 8mm）可闭式解位姿。
- 杆（圆柱+球头）：点云拟合轴线（圆柱 RANSAC）→ 杆尖 = 轴线顶端球心；倾角/方位由轴线方向反算。
- **精度**：确定性，亚毫米/亚度级；算力≈点云拟合（毫秒级，CPU）。

### 2.3 方案 B：深度聚类 + 基元拟合（贴近真实相机，无分割）
- 真实相机没有 geom id，用**“已知静态场景扣除”**做特殊过滤：
  - 静态部分（台面、基座、臂）在固定布局下**位置恒定**。可预渲染“无套筒无杆”的背景深度图 `depth_bg`；运行期 `|depth - depth_bg| > τ` 即为动态目标（套筒/杆）+ 臂。
  - 臂可用**正运动学**（`env.arm_qpos()` → FK）实时算出掩码并扣掉 → 剩套筒+杆。
  - 剩余点云用 2.2 的几何拟合得到位姿。
- 这正对应你说的“特殊的过滤算法”：**以根部基准 + 固定布局为背景模型，差分出目标**。

### 2.4 输出接口与精度指标
```python
def perceive(rgb, depth, seg=None) -> dict:
    return {
        "sleeve": {"pos": (3,), "axis": (3,), "conf": float},
        "rod":    {"pos": (3,), "axis": (3,), "tip": (3,), "conf": float},
    }
```
- 验收：套筒位置误差 ≤2mm、轴线角度 ≤2°；杆尖位置 ≤3mm、倾角 ≤2°。（仿真里用 GT 比误差即可，见 §7 测试。）

---

## 3. 第二步：稳定抓取路径规划

目标：由感知到的套筒位姿，生成**稳定、可复现**的抓取动作。

### 3.1 解析/脚本化抓取（首选，零训练）
- 直接复用现有成功链路：沿套筒轴线水平接近（`goto(sc, SLEEVE_AXIS, pre_offset=PRE_GRASP_OFFSET)`）→ 闭爪（`grip`，两段力矩：快速闭合→柔顺夹持）→ 微抬脱开 V 托架。
- 抓取目标位姿由感知套筒位姿算出（替代现在的 `env.sleeve_pose()` 真值）。
- **为什么够稳**：竖直套筒只在工作点附近可抓（已验证），布局固定 → 抓取几何恒定；横向柔顺（`LATERAL_GAIN=1.0, LATERAL_MAX=0.006`）吸收对位误差。

### 3.2 稳健化（梯度无关参数优化，不上 RL）
- 把“抓取稳定性”当作黑箱目标，在仿真里做**轻量参数搜索**（CMA-ES / 随机搜索），只调几个关键量：`PRE_GRASP_OFFSET`、闭合力矩档（`JAW_CLOSE_LIMIT/JAW_FORCE_LIMIT`）、抬升高度 `LIFT_DZ`、接近速度。
- 仿真快且确定性 → 数百次 rollout 即可收敛，**全程 CPU、分钟级**，远比重训 RL 便宜。
- 输出：一组“最坏倾角(20°/55°)+ 感知噪声”下成功率最高的参数。

### 3.3 （可选，最后才考虑）行为克隆小网络
- 仅当 3.1/3.2 在传统逻辑下仍不够稳时才做。
- 用 3.2 最优脚本策略在仿真采几千条 (感知→抓取6D) 样本，训一个**小 MLP**（输入感知 6D，输出抓取 6D），CPU 可跑、推理毫秒级。仍属“传统+轻学习”，非 RL。

### 3.4 路径平滑与约束
- 复用 `goto`/`goto_joint`（smoothstep 时间参数化）保证轨迹连续，不换 IK 分支（避免“先移后转”的离散分支问题，见 params 文档 §4）。
- 每步做关节限位 + 基座 ±110° 软约束检查（SO-100 硬限制）。

---

## 4. 第三步：基于感知的插入

目标：用第一步得到的**杆位姿**，把已夹住的套筒完整插入。

### 4.1 驱动现有对齐+推入
- 把 `env.rod_axis()` / `env.rod_tip()`（现为 GT）替换为 `perceive()` 的杆估计。
- `pre = rod_tip + rod_axis*(SLEEVE_LEN/2 + PRE_INSERT_GAP)`，`PRE_INSERT_GAP=0.012`。
- 复用“先移后转”：竖直平移到 `pre` → 关节空间把套筒轴转到 `rod_axis`（避免笛卡尔 IK 卡在竖直分支）。

### 4.2 闭环横向柔顺自定心
- 插入段每步用感知（或夹爪接触）测得的**横向偏心**喂给 `LATERAL_GAIN` 修正 → 套筒借喇叭口自定心（等效 RCC）。
- 感知噪声下仍能自定心，因为修正量是**闭环**的，不依赖单次精确位姿。

### 4.3 卡阻检测与停止
- 重叠量 `overlap` 停滞（多步不增）且接触力超阈 → 判为卡阻，停止推进（沿用现有 `jam` 逻辑：40 步无进展即停）。
- 成功判定沿用：释放前 `overlap≥30mm`、轴夹角≤8°、偏心≤4mm。

## 5. 算力与实时性预算（全 CPU）

| 模块 | 方法 | 单帧算力 | 说明 |
|---|---|---|---|
| 感知 | 分割/深度聚类 + 几何拟合 | 1–5 ms | 无神经网络；点云拟合可降采样 |
| 抓取规划 | 解析 IK（pose_ik） | 每步几 ms | 已有，可加参数查表 |
| 插入 | IK + 柔顺修正 | 每步几 ms | 闭环但便宜 |
| 仿真步进 | MuJoCo | ~ms 级 | FPS=30 余量充足 |

**结论**：整链路在普通 CPU 上实时跑满 30Hz 无压力，无需 GPU、无需在线学习。

## 6. 里程碑（建议交付顺序）

- **M0 — 端到端打通（用完美感知）**：`perceive()` 先用仿真分割/GT，把①②的输出接进现有 `run_scripted_insert`，证明“真值→感知接口→控制器”管线通。改动最小、风险最低。
- **M1 — 真实感感知**：实现 §2.3 深度聚类+背景扣除（无分割），加合成噪声/遮挡测试，验证位姿误差达标。
- **M2 — 抓取稳健化**：§3.2 梯度无关参数优化，覆盖 tilt∈{20,35,50} + 感知噪声，固化参数。
- **M3 — sim-to-real 硬化**：相机噪声/光照/臂部遮挡建模，延迟与功耗 profiling，必要时上 §3.3 小 BC 网络。

## 7. 测试与验收

- 新增 `perception_demo.py`：渲染 `base_rgbd`，跑 `perceive()`，打印估计位姿 vs GT 误差（mm/°）。
- 回归测试：对 `tilt∈{20,35,50}` 各跑完整三步（感知→抓取→插入），断言成功率 100%（仿真确定性）。
- 噪声回归：在感知输入叠加高斯噪声/随机 dropout，要求成功率仍 ≥ 设定阈值（如 95%）。

## 8. 主要风险与对策

| 风险 | 对策 |
|---|---|
| 仿真有完美分割，真实相机没有 | M1 用深度聚类+背景扣除，不依赖分割 |
| 布局固定 → 感知“作弊” | 背景扣除/几何拟合依赖几何而非记忆，可迁移到真实相机（同布局） |
| 杆被臂遮挡时感知失败 | 插入段改闭环横向修正兜底；感知只在“臂缩回”时取一帧基准 |
| 倾角边界(20°/55°) 抓取不稳 | M2 参数优化专门覆盖边界 + 柔顺增益余量 |
