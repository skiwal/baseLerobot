# SO-100 套筒插装任务 — 参数与布局记录

> 状态：**布局已锁定，长期不变**。本文记录当前已验证可用的机械臂 / 工作台 / 套筒 / 细杆的
> 世界坐标位置、几何尺寸、以及插装算法用到的一切可调参数。后续只改算法，不改这些位置。
> 部署倾角方向固定为 **世界 +x（azim=0）**：杆座在 −x 侧（机器人右手边），杆朝 +x（左手边）倒。

---

## 1. 已固定的世界坐标布局（单位：米）

机械臂基座在原点 `(0,0,0)`。以下位置在仿真里由 `reset()` / `set_rod_pose()` 直接写入，
会**覆盖** XML 里的初值——**以 Python 常量 `SLEEVE_HOME` / `ROD_HOME` 为准**。

| 物体 | 位置 (x, y, z) | 说明 |
|---|---|---|
| SO-100 基座 | `(0, 0, 0)` | 基座 Rotation 关节范围 ±110°（见 §5），限制可达方位 |
| 工作台 `work_table` | body `(0, -0.22, 0)`；geom 半长 `(0.165, 0.06, 0.04)` + z 偏移 `0.04` | **顶面 z = 0.08**；覆盖 x∈[-0.165,0.165], y∈[-0.28,-0.16] |
| **套筒 `SLEEVE_HOME`** | `(0.120, -0.235, 0.110)` | **竖直**立于台面（台面 0.08 → 中心 0.11）。抓取只在此点附近稳 |
| **细杆座 `ROD_HOME`** | `(-0.040, -0.235, 0.085)` | 与套筒同 y；x 取负 = **−x 侧 = 机器人右手边**；杆朝 **+x（左手边）** 倒（azim=0） |
| 杆座静态立柱 `rod_post` | body `(-0.06, -0.20, 0.045)` | 装饰/承托（杆实际由脚本定位于 `ROD_HOME`） |
| 杆+座 `rod_rest` | body `(-0.06, -0.20, 0.085)` | 同上，静态 |
| V 型托架 `sleeve_cradle` | 两柱 y=-0.206 / -0.166，x=0 | 装饰（套筒现由脚本定位，不依赖托架承托） |
| 相机 `closeup` | `(0.20, -0.40, 0.26)` fovy=50 | 录视频用 |
| 相机 `side` / `top` | `(0.38,-0.46,0.33)` / `(0.06,-0.33,0.56)` | 观测视角 |
| **相机 `base_rgbd`** | `pos=(0.08,-0.04,0.30)` 朝 `(0.04,-0.235,0.10)` fovy=50 | **RGB-D 感知相机, 装在机械臂根部(略微偏机器人左手边 +x 并抬高, 避臂穿模)**; 视野覆盖套筒+杆工作区 |

> 实测硬约束：竖直套筒的夹抓姿态**只在工作点 (0.12, −0.235) 附近成立**（x=0.06 就抓不住）。
> 因此套筒位置被钉死在这里，不能“随便放”。

## 2. 几何参数

### 套筒（空心六边形近似圆柱，16 片壁板拼成）
| 参数 | 值 | 常量 |
|---|---|---|
| 对边距离（flat-to-flat） | 26 mm | `SLEEVE_AF` |
| 外接圆半径 | 15 mm | `SLEEVE_R_CIRC` |
| 内孔内切半径 | 8 mm | `SLEEVE_R_IN` |
| 长度 | 60 mm | `SLEEVE_LEN` |
| 轴线 | 竖直 Z | `SLEEVE_AXIS = Z_AXIS` |
| 密度 / 壁摩擦 | 900 / 1.8 | XML `density`/`friction` |
| 内孔导入喇叭口 | 16 片 `sleeve_ch_*`（8mm→11mm 锥面） | 用于插装自定心 |

### 细杆
| 参数 | 值 | 常量 |
|---|---|---|
| 半径 | 4 mm（原 5 mm；减径使内孔单边间隙 3mm→4mm） | `ROD_R` |
| 露出长度 | 80 mm | `ROD_LEN` |
| 杆尖 | 半球帽（球头，半径 4 mm） | `rod_tip_cap` |
| 倾角基准轴 | 竖直 Z（倾角 0 = 竖直向上） | `ROD_REF_AXIS = Z_AXIS` |

> 内孔-杆 **径向单边间隙 = SLEEVE_R_IN − ROD_R = 4 mm**，是干净插入的上限（见 `LATERAL_TOL`）。

## 4. 插装算法参数（6 段流程：接近→闭爪→抬起→对准→推入→收尾）

### 4.1 抓取段
| 参数 | 值 | 含义 |
|---|---|---|
| `GRASP_SEED` | `[0.28, -2.60, 2.65, -0.05, -1.57]` | IK 种子（Rotation, Pitch, Elbow, Wrist_Pitch, Wrist_Roll）；手指水平、z_h 竖直 |
| `HOVER_DZ` | 0.055 m | 悬停：夹持中心在套筒中心正上方 5.5 cm |
| `LIFT_DZ` | 0.050 m | 抓起后竖直抬起 5 cm（脱离 V 托架） |
| `PRE_GRASP_OFFSET` | 0.0025 m | 接近时手部沿夹紧方向偏置，固定侧垫片不蹭套筒 |
| `SLEEVE_JITTER_M` | 0.006 m | 套筒摆放位置抖动 |
| `JAW_OPEN` | 1.4 rad | 张开角 |
| `GRIP_SQUEEZE` / `GRIP_EXTRA_SQUEEZE` | 0.001 / 0.001 m | 过盈（两指间距比套筒外径小 1~2 mm） |
| `JAW_CLOSE_LIMIT` | 3.5 Nm | 闭合阶段力矩上限（快速闭爪） |
| `JAW_FORCE_LIMIT` | 0.40 Nm（≈24 N） | 夹住后力矩上限（拖动套筒不滑脱） |
| `GRIP_FORCE_TARGET` | 2.0 N | 接触判据：夹持力超此值切到柔顺档 |
| `_outer_r` | 0.013 m（= `SLEEVE_AF/2`） | 夹爪半对边距；`jaw_grip` 开口 = 2×0.013 − 0.001 = 25 mm |

> 接触分组：仅夹爪 8 个垫片与套筒接触（指侧碰撞体不与套筒碰），避免下降时侧向力把套筒推歪。

### 4.2 对准段（“先移后转”）
| 参数 | 值 | 含义 |
|---|---|---|
| `PRE_INSERT_GAP` | 0.012 m | 对准时套筒端面离杆尖 12 mm（不接触） |
| `CLEAR_GAP` | 0.030 m | 粗对准点再往杆外退 30 mm（先对轴线再推进） |
| 段1 | 竖直平移到 `pre`，轴仍竖直 | `goto(pre, SLEEVE_AXIS, 1.3s)` |
| 段2 | 在 `pre` 处关节空间把轴从竖直转到 `rod_axis` | `ik_restart(..., n_rand=800, max_step=0.06, n_iter=300, clamp_ref=X_AXIS)`；`goto_joint(1.2s)` |
| 对准段夹持 | `set_jaw_force_limit(0.8)` | 更紧，防套筒轴向滑脱 |
| `IK_RNG` | `default_rng(42)` | IK 多起点固定种子 → 每步候选序列确定、结果可复现 |

> 必须用关节空间插值绕过“竖直/倾斜”两个离散 IK 分支；笛卡尔逐步 IK 会在该位姿卡在竖直分支。

### 4.3 推入段（限幅推进 + 横向柔顺 RCC + 卡阻保护）
| 参数 | 值 | 含义 |
|---|---|---|
| `insert_speed` | 0.00015 m/步（≈4.5 mm/s @ 30 Hz 控制率） | 每步沿 −rod_axis 单调推进 |
| `max_insert_steps` | 600（≈20 s） | 推入步数上限 |
| `force_limit`（安全阀） | 40 N | 杆-套筒接触力超此值停，不再硬顶 |
| `target_overlap` | 0.034 m (34 mm) | 达到即停 |
| `LATERAL_GAIN` | 1.0 | 横向柔顺增益：修正目标 = −gain × 实测偏心（等效 RCC） |
| `LATERAL_MAX` | 0.006 m (6 mm) | 横向修正上限（留活动量） |
| 卡阻判据 | 重叠 40 步（≈1.3 s）无增长 → 判定卡阻 | 看“实际重叠有没有在长”，不看目标超前量（臂稳态滞后 ~2mm 会误判） |
| 推入段夹持 | `set_jaw_force_limit(0.7)` | 高倾角时套筒受重力矩易在爪里转，稍紧防漂 |

> 横向柔顺 = 等效远端柔顺中心（RCC）：横向位置环不钉死目标，而是闭合在“实测偏心”上，
> 杆尖顶着喇叭口产生侧向力时整手带着套筒往杆轴让开（而非楔死在刚性垫片间），喇叭口自定心。
> 实测：夹持力从 455N 降到 16~32N，杆-套筒力归零（不卡）。

## 7. 为什么锁定 +x（azim=0），以及 +y 为什么做不到

- 竖直套筒抓取只在工作点 `(0.12, −0.235)` 附近稳定（x=0.06 就抓不住）。
- 在该固定点，SO-100 仅 5 自由度的工作空间**只能**把工具朝 **+x（azim=0）** 和 **−y（azim=270）** 倾，
  朝 **+y（azim=90）/ −x（azim=180）** 会顶到腕部极限（约差 10° 到不了位）。
- 基座 Rotation 仅 ±110°，**整臂 180° 镜像也够不到**原任务点，故无法通过“换一只手”翻转到 +y 半球。
- 因此部署方位固定为 **azim=0（+x = 机器人左手边，杆在 −x 右手边）**，三档倾角全部通过。
- 若要真正支持世界 +y（任意方位）倾斜，须回到场景原始设计——**套筒横躺**（夹爪从侧面 ±x 夹，
  杆水平方向任意倾斜都不和竖直下降路径冲突），并重写抓取/对准/推入链路。当前版本在
  `reset()` 把套筒强制竖直，已放弃横躺的通用性。

## 8. 根部 RGB-D 相机（感知用）

机械臂基座处新增一台 RGB-D 相机 `base_rgbd`（见 §1 布局表），用于"机械臂不伸出去"时
感知套筒与杆、做抓取规划。

- **几何**：`pos=(0.08,-0.04,0.30)`，朝工作区中心 `(0.04,-0.235,0.10)`，fovy=50；基座 link 静止于原点，
  相机即等同于"根部"固定机位；略微偏 +x 并抬高以避开机械臂、避免穿模。
- **取景**：套筒(0.12,-0.235,0.11) 与杆座(-0.04,-0.235,0.085) 均落在画面内（H=480,W=640 投影约 (116,207)/(533,283)）。
- **深度**：MuJoCo 3.14 `mujoco.Renderer` 用 `enable_depth_rendering()` / `disable_depth_rendering()` 切换，
  `render()` 返回 (H,W) float32（米）。**注意**：渲染视角用的是编译后的 `cam_mat`，不要用 `camera.mat0`
  做投影比对（两者在多次 render 后可能不一致）；判定可见性请用分割渲染（`enable_segmentation_rendering()`）。
- **代码**：`SO100SleeveEnv.render_rgbd(camera="base_rgbd") -> (rgb, depth)`。
- **采样/校验脚本**：`so100_sim/capture_base_cam.py`（臂置"缩回抬高"姿态，分割渲染确认两者可见，并保存
  `out/base_rgbd_rgb.png`、`out/base_rgbd_depth.png`、`out/base_rgbd_depth.npy`）。
- **遮挡说明**：相机从基座看工作区，臂伸出去（朝任务前伸/折叠在中间）会挡视线；这正是预期——
  仅在"臂缩回"时使用该相机即可同时看到套筒与杆。
